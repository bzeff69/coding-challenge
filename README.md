# Streak — Track habits. Get judged.

A gamified habit tracker with humor and consequence. Track daily habits, build streaks, get roasted when you miss a day, and celebrate (sarcastically) when you succeed.

## Features

### Habit Management
- Create habits with a custom name, daily target (1-10), and color
- Edit habit name, daily target, and color at any time
- Soft-delete habits (move to trash) with two-step confirmation
- Restore soft-deleted habits from the trash
- Permanently delete habits from the trash with confirmation
- View deleted habits list with their stats preserved
- 8 color options: Indigo, Violet, Rose, Pink, Orange, Amber, Teal, Cyan
- Color picker with hover scale animation and ring-outline selection indicator
- Form validation with inline error messages for empty names and out-of-range targets
- Auto-focus on the name input when creating or editing

### Daily Tracking
- Tap to increment today's count toward your daily target
- Undo button to subtract from today's count
- Progress bar with smooth 300ms animated fill
- Live counter showing current count vs. daily target (e.g. "3 / 5")
- "Done" badge when daily target is reached
- Button disables when target is complete (prevents over-counting)
- Undo disables when count is 0

### Streaks & Statistics
- Current streak tracking (consecutive completed days from today)
- Best (longest) streak tracking across all time
- Total completed days counter
- Success rate percentage (completed days / tracked days)
- Automatic missed-day detection on app load
- Streak resets when a day is missed
- Stats recalculate in real time after every action

### History
- 7-day rolling history strip on each habit card
- Week-by-week navigation with left/right arrows
- Date range display (e.g. "Mar 27 — Apr 2")
- Day cells color-coded: green checkmark (complete), tilde (in-progress), red X (missed), dashed border (today, empty)
- Inline day editor: tap any day cell to set its count with number buttons (0 to daily target)
- "View full history" link opens 90-day calendar grid
- Full history modal: 13 weeks x 7 days grid with date labels
- Full history uses same color coding and inline editor as the strip
- Legend explaining each status icon

### Humor & Messages
- Context-aware funny messages on every action
- 4 message categories: progress, completion, undo, missed day
- 16 unique messages per category (64 total)
- Messages reference habit state (e.g. streak length, count progress)
- Flash animation: message background flashes indigo/bright for 2.5 seconds, then fades to subtle
- Flash only triggers on new messages (tracked by timestamp to prevent duplicate flashes)
- Sarcastic, roast-style tone throughout (e.g. "Your streak died alone. No funeral will be held.")

### Dashboard
- Modal overlay with aggregate analytics
- 4 stat cards with gradient backgrounds: Today's progress, Total Completions, Best Streak, Avg Success Rate
- 30-day activity heatmap with 4 intensity levels
- Heatmap cells have tooltips showing date and completion percentage
- Heatmap legend (Less → More)
- Total actions tracked counter (large, prominent display)
- Per-habit breakdown table with: color dot, name, inline progress bar, completion %, days completed, best streak
- Deleted habits toggle: show/hide deleted habits in the dashboard with their stats
- Deleted habit rows display at 50% opacity with "deleted" badge

### PDF Export
- Export dashboard as PDF via browser print dialog
- Forces light-mode colors when printing from dark mode (removes dark class, restores after)
- Print-specific header with "Streak Dashboard" title and export date
- Print-specific footer with "Generated by Streak — Track habits. Get judged."
- Hides all non-dashboard content during print via CSS `visibility: hidden`
- Forces `print-color-adjust: exact` for accurate gradient and color reproduction
- Light-mode heatmap variables forced in `@media print`

### Dark Mode
- Toggle between light and dark themes
- Detects system preference (`prefers-color-scheme`) on first visit
- Persists theme choice in localStorage
- Sun/moon icon toggle in the header
- Full dark palette using Tailwind stone color scale
- Heatmap colors swap to dark-optimized palette
- All components, modals, and overlays support both themes

### Responsive Design
- Mobile-first layout
- Sticky header on all screen sizes
- Desktop: inline toolbar with Dashboard, Dark Mode, Deleted Habits, and Add Habit buttons
- Mobile: three-dot hamburger menu that expands to a dropdown with all actions
- Dropdown closes on outside click or action
- Stat card grid: 2 columns on mobile, 4 on desktop
- Habit cards and modals fit within viewport with scroll support

### Confetti & Celebrations
- Confetti explosion animation when a habit reaches its daily target
- 35 randomized colored particles with physics-based fall + spin + drift
- Auto-cleans up after 1.8 seconds
- "All Done Today" celebration banner when every habit is completed
- Gradient banner (emerald → teal → cyan) with pulse animation
- 5 rotating celebratory messages (e.g. "Perfect day. Screenshot it. Nobody will believe you.")

### Streak Milestones
- Special celebration messages at 7, 14, 21, 30, 50, 100, and 365 day streaks
- Overrides normal completion message (e.g. "A WHOLE WEEK?! Who ARE you?!")
- Escalating hype as streaks get longer

### Dynamic Page Title
- Browser tab shows live progress: "2/3 done | Streak"
- Updates in real time as you complete habits
- Shows just "Streak" when no habits exist or still loading

### Keyboard Shortcuts
- `N` — Open new habit form
- `D` — Open dashboard
- `T` — Toggle dark/light mode
- `Escape` — Close any open modal, form, or menu
- Shortcuts disabled when typing in input fields

### Animations & Visual Polish
- Skeleton loading screen with shimmer animation (3 placeholder cards pulse while data loads)
- Staggered card entrance: habit cards fade + slide up with 60ms stagger per card
- Green glow pulse aura on completed habit cards (animated box-shadow)
- Shimmer adapts to dark mode (dark gradient tones)

### UI & Polish
- Custom flame logo SVG with multi-layer gradient (amber → red → pink → violet), glow filter, inner flame, bright core, and spark accents
- Matching flame favicon in the browser tab
- App title "Streak" with tagline "Track habits. Get judged."
- Smooth transitions on buttons, progress bars, and message banners
- Hover and active states on all interactive elements
- Disabled states with visual feedback (greyed out, cursor changes)
- Tooltips on icon-only buttons
- Empty state screen: tilde icon, "No habits yet. Chaos remains undefeated." with CTA button
- Empty trash screen: trash icon with "Nothing here" message
- Modal overlays with semi-transparent black backdrop
- Collapsible habit cards (click to expand/collapse)
- Collapsed view shows: color dot, name, count/target, mini progress bar, checkmark if done
- Loading state displayed while fetching initial data from API

### Backend & Persistence
- ASP.NET Core 8 Minimal API with 9 REST endpoints
- SQLite database with JSON blob storage (single-row `app_state` table)
- Thread-safe database access with lock-based concurrency
- All business logic ported from TypeScript to C# (streak calc, missed-day detection, stats)
- Missed days processed server-side on every state load
- CORS enabled for all origins

### Infrastructure
- Docker Compose with two services: `api` and `frontend`
- Named Docker volume (`habit_data`) for persistent SQLite storage
- Multi-stage Docker builds for both frontend and backend (minimal image sizes)
- nginx reverse proxy: serves SPA with `try_files` fallback, proxies `/api/` to backend
- Vite dev server with proxy to Docker API for local development
- Frontend served on port 3000, API on port 5001 (host) / 5000 (container)

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS v4
- **Backend:** ASP.NET Core 8 Minimal API, SQLite
- **Infrastructure:** Docker Compose, nginx reverse proxy

## Running with Docker

Prerequisites: [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.

```bash
# From the project root
docker compose build
docker compose up -d
```

The app will be available at **http://localhost:3000**.

- Frontend is served by nginx on port 3000
- API runs internally on port 5000, proxied via nginx at `/api/`
- Data persists in a Docker volume (`habit_data`)

To stop:

```bash
docker compose down
```

To stop and remove all data:

```bash
docker compose down -v
```

## Development (without Docker)

Prerequisites: Node.js 22+, the API container running for backend.

```bash
# Start the API container
docker compose up -d api

# Install dependencies and start dev server
npm install
npm run dev
```

The Vite dev server runs at **http://localhost:5173** and proxies `/api` requests to the Docker API on port 5001.
